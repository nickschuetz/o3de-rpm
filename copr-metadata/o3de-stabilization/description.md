Open 3D Engine: pre-release engine-validation builds from upstream's `stabilization/<release>` branch (currently `stabilization/26100`, the 26.10 pre-release line, cut 2026-08-11). Active during the upstream stabilization window (~4 weeks per release cycle); dormant between cycles. When upstream tags and merges to `main`, the released content lands in `hellaenergy/o3de`; this channel then rolls over to track the next major's stabilization branch.

Community-tester channel during active stabilization windows. For routine post-release packaging-fix validation between cycles, use `hellaenergy/o3de-testing` instead (mirrors Fedora's `updates-testing` semantics; pre-promotion soak for the stable channel).
