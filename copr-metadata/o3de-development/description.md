Open 3D Engine -- builds from upstream's `development` branch tip, refreshed automatically by a weekly Sunday cron (skipped when the upstream tip has not moved since the last build). For stable releases, use hellaenergy/o3de (tracks upstream's main branch). For pre-release validation of the next release line, use hellaenergy/o3de-stabilization. For an in-progress migration branch, a dedicated per-branch COPR project is created rather than overloading this one (as was done for the Qt6 migration, which has since merged into development).
