Open 3D Engine: experimental builds. Tracks upstream's `development` branch (like hellaenergy/o3de-development: Qt6, bleeding edge). Currently a native-Wayland preview for Fedora 44 and 45 (Wayland window and Vulkan surface path compiled in, plus local Editor UI fixes for Wayland and XWayland), built but not yet hand-tested. Packagers' sandbox for work not yet ready for community testers; don't enable this repo unless you know what you're getting.
